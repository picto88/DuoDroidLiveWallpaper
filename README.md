- Android dengan sensor **gyroscope** (wajib, karena efek shader bergantung pada data sensor ini)

## English

An Android live wallpaper featuring dynamic shader animations, inspired by the **Apple Duo Fold** visual effect. The wallpaper responds to device movement in real time using the gyroscope sensor, creating a smooth depth and motion effect whenever the phone is moved.

### ✨ Features

- 🎨 Smooth, responsive real-time shader animation
- 📱 Visual effect inspired by Apple Duo Fold
- 🌀 Motion response based on gyroscope sensor data
- 🔄 Built-in auto-update (no Play Store required)
- ⚡ Lightweight and optimized for a wide range of Android devices

### 📋 Requirements

- An Android device with a **gyroscope** sensor (required, as the shader effect depends on this sensor data)
- Minimum Android [fill in minimum version, e.g. 7.0 / API 24]
